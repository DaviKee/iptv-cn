# iptv-cn · 中国公开免费直播源（每日自动测活更新）

每天早上 9 点（北京时间）自动从 [iptv-org/iptv](https://github.com/iptv-org/iptv) 拉取中国公开免费频道，
逐条探测流是否存活，剔除失效源后生成一份干净的 m3u 订阅文件。**盒子/电视里填一次地址即可长期使用。**

## 订阅地址（二选一）

| 链接 | 适用场景 |
|---|---|
| `https://cdn.jsdelivr.net/gh/DaviKee/iptv-cn@main/iptv-cn.m3u` | **国内设备推荐**（jsDelivr CDN，raw 直连不稳时用它） |
| `https://raw.githubusercontent.com/DaviKee/iptv-cn/main/iptv-cn.m3u` | 海外网络 / 已有代理的设备 |

> jsDelivr 有缓存（最长约 12 小时），当天更新可能延迟反映，属正常现象。

## 怎么用

- **FongMi 影视TV / TVBox 系**：设置 → 直播 → 直播源，填上面的订阅地址。
- **Kodi / 其它播放器**：直接当作 m3u 播放列表导入。
- 频道已按「央视 / 卫视 / 地方及其他 / 需国内网络」分组，`group-title` 字段可用。

## 更新机制

- 定时：GitHub Actions 每天 UTC 01:00 运行（北京时间 09:00），也可在 Actions 页手动触发。
- 探测：每条流下载首包验证（HLS 校验 `#EXTM3U` 标签），12 秒超时，失败即剔除。
- 例外：带 `[Geo-blocked]` 标记（仅限特定地区观看）的频道在海外探测失败属预期，会保留并归入「需国内网络」分组，国内网络下自行验证。

## 说明

- 频道数据全部来自 iptv-org 项目的公开收集，版权归各播出机构所有；本仓库只做聚合、测活与格式转换，不含任何私有/盗版源。
- 公开免费流天然不稳定，失效是常态——这正是本仓库存在的原因，第二天自动更新即可。
